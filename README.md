# Custom Header File in C

## Project Description

A simple C program that demonstrates how to create and use a custom header file. The program contains arithmetic functions in `operations.h` and uses them from the `main.c` file.

The project also demonstrates preprocessor directives such as `#include`, `#ifndef`, `#define`, and `#endif`.

## Features

- Create a custom header file
- Use `#include` to include the header file
- Perform addition using a function
- Perform multiplication using a function
- Demonstrate header guards
- Separate functions from the main program

## Technologies Used

- C
- C Preprocessor
- Header Files
- `#include`
- `#ifndef`
- `#define`
- `#endif`
- Functions
